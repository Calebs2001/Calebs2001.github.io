C++ Console Application

Bowling Sim

Bowling Sim is a c++ console based game. You can bowl 10 frames of bowling to try and strategize the best ball to use for the best possible score. You can also practice, or look at the leaderboard of your previous scores to try and set a new personal best.

Key Features

  • Score multiplying: If you get a strike your score is adds together your next two throws. If you get a spare, it adds your next throw.
  • Clean ball: The more you roll your ball, the lower chance you have at getting a strike. Know the right time and when to clean your ball. But be careful, not all balls go back to normal.
  • The only inputs required for the user other than one all requires the user to input a number from 1 to however many options there are. If the user inputs a number that is not there, the program asks them to try again.

What I Learned

I never made anything that had to keep track of multiplying a score twice, or once, or only one time, and how to add it all up in the end for a specific index in a vector. I learned that you need to use if and else if statments, refernces, and static casts in order to get everything to work propperly.
